# labels

学習ターゲットとなる疑似ラベルと、gold-58(放射線科医の正解)を扱う。

## 責務

- 公開されているレポート由来ラベル(すべて CC0)を、共通の形式で読み込む
- ソースごとに違う「レポートに記載なし」の表現を、記載有無のマスクに統一する
- 記載なしセルの値と損失の重みを、所見ごとの方針で決める
- 学習データから gold-58 を除外する

予定: 複数ソースのブレンドや OOF 予測との混合(自己蒸留)は `blend.py` に置く。

## ファイル

### `public.py`

| 名前 | 役割 |
|---|---|
| `load_train_labels(name, silent_weight)` | 学習用の(ラベル, 重み)を返す。gold-58 は除外。通常はこれだけ使う |
| `load_source(name)` | ソースを `LabelSet` として読み込む |
| `apply_silence_policy(ls)` | 記載なしが実質陰性の所見について、記載なしセルを陰性寄りの値に置き換える |
| `loss_weights(ls, silent_weight)` | 損失の重み(記載あり 1、記載なし `silent_weight`) |
| `load_gold()` | gold-58 の 0/1 ラベル |
| `TARGETS` | 12 ラベルの列名(提出ファイルと同じ順) |
| `SOURCES` | ソース名 → (ファイル, 記載なしの値) |
| `SILENT_MEANS_ABSENT` | 記載なしを陰性とみなす所見と、その置き換え値 |

## データ形式

- `LabelSet.y`: DataFrame。index は `StudyInstanceUID`、列は `TARGETS`、値は確率 [0, 1]
- `LabelSet.addressed`: 同じ形状の bool。レポートに記載があれば True
- 重み: 同じ形状の float

## ソース

公開ラベルは `data/labels/<owner>_<dataset>/` に置く(Kaggle Dataset をそのまま展開したもの)。

| 名前 | 記載なしの値 | gold-58 macro AUC | 備考 |
|---|---|---|---|
| `steven_v4`(既定) | 0.25 | 0.893 | v2 と GPT-5.6-Sol ラベルのブレンド |
| `steven_v2` | 0.5 | 0.887 | |
| `jev` | なし | 0.903 | steven / pilkwang の列を gold-58 で選択しているので楽観値 |
| `consensus` | なし | 0.889 | 6 ソースの平均 |

steven_v4 はブレンド済みのため、0.25 を記載なしとみなすのは**近似**である。v4 の 0.25 は 10,093 セルで、うち 10,085 が v2 の記載なし(0.5)と一致する。8 セルは不一致で、逆に v2 では記載なしなのに v4 が 0.25 でないセルが 82 ある(全体の約 0.2%)。

## 記載なしの方針

| 所見 | 記載なしセルの値 | 重み | 根拠 |
|---|---|---|---|
| Baker's | 0.03 | 1 | gold-58 で、記載なしのときの陽性率が 3% |
| Medial OA | 0.0 | 1 | 同 0% |
| その他 | ソースの値のまま | `silent_weight`(既定 0.5) | 記載なしでも陽性があり得る(Synovitis は 34%) |

記載なしの値を持たないソース(jev、consensus)では、全セルが記載あり扱いになり、この方針は効かない。
